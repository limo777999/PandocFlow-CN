# PandocFlow - 现代化文档格式转换小工具 🚀

**PandocFlow** 是一个为 Windows 环境设计的桌面端文档格式转换小工具。它基于高性能的 **PyQt6** 编写现代化暗黑风 GUI 界面，底层调用学术界与工业界通用的 **Pandoc** 引擎，支持多种文档格式（如 `.md`, `.docx`, `.html`, `.rst`, `.txt` 等）的批量、多线程、拖拽式转换。

---

## 🌟 功能特性

1. **现代化 GUI 界面**：采用定制化的 Qt 样式表（QSS）设计的深色视口（Dark Theme），具备卡片式圆角布局、悬停高亮动画及分状态彩色灯光指示器。
2. **Pandoc 自动检测与修复提示**：
   - 首次启动程序时，会自动检查系统环境变量（`PATH`）及 Windows 常见默认安装路径下是否存在 Pandoc。
   - 若未检测到 Pandoc，程序会弹出现代化交互弹窗，提示用户安装，并提供一键复制命令行安装指令（`winget install jgm.pandoc`）以及官网下载链接。弹窗内支持【重新检测】。
3. **拖拽式快捷导入**：支持将单个/多个文档、甚至整个文件夹直接拖拽到软件界面中。程序会自动递归检索其中的受支持文档并添加进队列。
4. **多线程异步批量转换**：采用 PyQt6 的 `QThread` 线程池机制，文档转换在后台进程中异步进行，保证 GUI 界面在转换大型文件或几十个文件时绝不卡死，并实时更新进度和详细日志。
5. **灵活的转换配置**：
   - 支持全局一键更改目标格式，或在列表内对单个文件单独修改目标格式。
   - 支持默认输出到原文件同目录（输出名称与源文件相同仅后缀改变，且自动防止同名同后缀覆盖源文件），也可关闭后自定义全局输出文件夹。
6. **单文件 EXE 打包**：项目提供了一键打包脚本，可将所有依赖包和多模块代码打包成单个独立的 `.exe` 文件，双击即用，零依赖分发。

## 📦 快速使用（直接运行）

在本项目根目录下，已经为您编译好了单文件免安装版可执行程序：
👉 **`PandocFlow.exe`**

您只需双击运行即可！

### 首次使用 Pandoc 安装引导
若双击启动后提示“未检测到 Pandoc 环境”：
1. 点击提示框中的 **【复制】** 按钮以复制安装指令。
2. 按快捷键 `Win + X` 并选择 **终端** 或 **PowerShell**。
3. 右键粘贴并按回车运行：
   ```powershell
   winget install jgm.pandoc
   ```
4. 安装完成后，回到软件提示框，点击 **【重新检测】** 即可直接进入主界面。

## 💻 开发者指南（从源码运行）

若您希望在 Python 环境中调试或运行本工具：

### 1. 安装依赖
确保您的 Python 版本为 3.8+ (已在 Python 3.14 环境下测试通过)，在项目根目录下执行以下命令安装依赖：
```bash
pip install -r requirements.txt
```

### 2. 运行程序
```bash
python src/main.py
```

---

## 🛠️ 重新打包编译 EXE

如果您对源代码进行了修改，并希望重新打包成单个的 `.exe` 可执行文件：

运行打包脚本：
```bash
python build_exe.py
```
打包脚本将自动执行以下操作：
1. 调用 PyInstaller 扫描 `src/main.py` 的依赖链。
2. 清除缓存并使用 `--noconsole`（隐藏终端黑窗口）与 `--onefile`（打包成单文件）模式编译。
3. 编译好的文件位于 `dist/PandocFlow.exe`，并会被自动复制一份到项目的**根目录**下覆盖旧版本，方便分发。

## 📂 项目目录结构说明

```
joyful-rutherford/
├── src/                  # 源代码文件夹
│   ├── __init__.py       # 包初始化文件
│   ├── main.py           # GUI 主程序、拖拽区域、表格操作及全局逻辑
│   ├── converter.py      # QThread 异步转换核心工作线程
│   ├── utils.py          # Pandoc 环境检测、版本检查工具函数
│   └── styles.py         # 全局 QSS 现代化暗黑风格样式表
├── build_exe.py          # PyInstaller 编译自动化脚本
├── requirements.txt      # Python 依赖清单
├── README.md             # 本说明文档 (中文/英文使用手册)
└── PandocFlow.exe        # [打包生成] 根目录下最终生成的单文件 exe 应用程序
```

## ⚠️ 常见格式转换注意事项
- **Markdown (.md) ➔ Word (.docx)**：完美支持，Pandoc 的原生主打转换。
- **Word (.docx) ➔ Markdown (.md)**：完美支持，会自动转换图片及标题层级。
- **转换为 PDF (.pdf)**：最新版 EXE 已内置 Typst PDF 引擎，可直接转换；源码构建时可将 `typst.exe` 放入 `engines` 目录，或通过 `TYPST_EXE` 指定路径。
